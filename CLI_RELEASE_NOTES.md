# Ayin-Relay Windows connector preview v__VERSION__

This prerelease contains the unsigned Windows connector EXE for inspection before Authenticode signing. Windows setup requires matching valid publisher signatures on the installer and node.

The installer contains no device credentials. Device enrollment uses an authenticated browser session and on-device confirmation.

See the [Windows connector guide](https://github.com/AYin-Z/Ayin-Relay/blob/__TAG__/desktop/connector/README.md) for the current Windows installation and recovery options. Verify the downloaded file against the SHA-256 in the attached `preview.json`.
